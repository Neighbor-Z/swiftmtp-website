SwiftMTP Privacy Policy

Last Updated: August, 2026

1. General Privacy Principle

SwiftMTP, in its core functionality, operates entirely locally as a standalone application. The software itself does not collect, store, transmit, or process any personal data, user information, or file contents, nor does it require any privacy-invasive permissions to perform its primary device management functions. However, if you voluntarily elect to enable and utilize the supplemental artificial intelligence functionalities ("AI Features"), specific data processing may occur as explicitly outlined in the subsequent sections of this agreement.

2. Acceptance of Terms

This disclosure notice explains the terms of use governing the artificial intelligence features ("AI Features") integrated into the SwiftMTP application. When you first switch the AI Mode from "None" to any other option in Settings, you must read and agree to all terms before activating these features. By enabling or utilizing the AI Features, you acknowledge that you have read, understood, and agreed to be bound by these terms. AI features must be manually triggered by the user; no automated background processing is enabled without explicit user initiation.

3. Data Processing and Privacy

3.1. On-Device Local Processing (Apple Foundation Models). When utilizing Apple Foundation Models, all inference and data processing are performed entirely on your local hardware. These on-device models process all information locally on your Mac. This functionality requires macOS 26 or later with Apple Intelligence enabled.

3.2. Metadata Handling in API Mode. When utilizing the software in API mode, limited item metadata (including, but not limited to, file names, file types, and file sizes) and device information (such as hardware model and USB connection status) may be transmitted to the designated third-party AI provider. This transmission is strictly limited to the purpose of building necessary context for your explicit requests.

3.3. Protection of File Contents. Notwithstanding the transmission of metadata in API mode, the actual contents of your files will never be uploaded, transmitted, or shared with any third party under any circumstances.

3.4. API Key Storage and Transmission. If you choose to utilize the API mode, any API key you provide is stored entirely locally on your device. Your API key is only transmitted directly to your chosen AI service provider for the strict purpose of authentication when you manually and actively initiate an AI request.

4. Accuracy and Disclaimer of Warranties

Artificial Intelligence systems are subject to error and may generate inaccurate, incomplete, or unexpected results. You acknowledge and agree that it is your sole responsibility to independently verify all results provided by the AI Features prior to performing any critical file operations. The AI Features are provided strictly on an "as is" and "as available" basis without warranties of any kind.

5. Third-Party API Costs and Liability

When operating the AI Features in API mode, you understand and agree that you are solely responsible for any and all usage costs, fees, or charges incurred directly from your chosen third-party AI provider. Furthermore, you shall bear full responsibility and liability for any damages, losses, or unauthorized charges resulting from the improper use, leakage, or mismanagement of your API key.

6. Development Status and Modifications

You acknowledge that the AI Features provided within SwiftMTP are currently under active development. The functionality, accuracy, user interface, and scope of these features remain subject to change, modification, or removal in future software updates without prior notice. Consequently, this privacy policy and terms of use agreement will be continuously updated to reflect such ongoing developmental changes.
